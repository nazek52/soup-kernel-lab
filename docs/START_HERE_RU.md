# Как пользоваться Soup Kernel Lab

Репозиторий уже создан: https://github.com/nazek52/soup-kernel-lab.
Команда хакатона для запуска этого самостоятельного проекта не нужна.

## Что можно сделать сейчас

1. Скопировать проект через GitHub Code → Download ZIP или git clone.
2. Установить зависимости командами из README.
3. Выполнить `python -m soup_lab demo --open`.
4. Посмотреть HTML-отчёт с реальными ошибками loss и градиентов.
5. Запустить тесты `python -m pytest solution dev_tests -q`.

CPU-демонстрация показывает математический алгоритм. Собственные Triton-ядра
проверяются отдельно в CI через CPU-интерпретатор и на CUDA через gpu-test.

## Реальное обучение

Импортируйте notebooks/kaggle_submission.ipynb в свой Kaggle.
Настройки: GPU T4 x2, Internet on. URL GitHub уже заполнен.
Далее Run All: установка, тесты, обучение base/solution, оценка качества и проверки правил.
Не запускать параллельно другие GPU-задачи. Код использует одну T4.
Два повторения каждой стороны могут занять 20–30 минут плюс загрузка/установка.

Для запуска нужен вход в Kaggle. Доступ к бесплатной GPU может требовать подтверждения телефона.
Токены в код, чат и Git вставлять не нужно. Для Hugging Face необязательный токен хранится в Secrets.

## Как читать итог

Нужны 10/10 PASS. Доля собственных ядер должна составлять минимум 5% времени обучения.
SwiGLU из starter в неё не входит. Результаты смотрите в runs/result.json и runs/checks.json.
Не считайте CPU-тесты подтверждением скорости или качества модели.

Для публичного доказательства сохраните версию через Save Version → Save & Run All,
сделайте notebook public и добавьте ссылку с scriptVersionId в README и SUBMISSION.

## Про конкурс

Личный репозиторий не заменяет репозиторий, выданный платформой, для оценки конкурса.

Гайд AI CASE, приложенный в переписке, относится к Decentrathon 2.0 и не меняет задачу Soup.
