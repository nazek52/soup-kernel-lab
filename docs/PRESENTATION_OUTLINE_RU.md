# Содержание презентации, 6 слайдов

Заготовка содержания. Итоговый файл презентации нужно завершить после Kaggle-прогона.

## 1. Soup Kernel Challenge
RMSNorm и cross-entropy на Triton. Название команды и статус результатов.

## 2. Фиксированная задача
Qwen2.5-1.5B-Instruct, NF4, LoRA rank 16, 256 казахских инструкций,
64 шага на одной Kaggle T4. Цель: меньше полного времени или пикового расхода памяти
при сохранении качества. Настройки обучения фиксированы.

## 3. Cross-entropy по блокам
Словарь разделён на блоки по 4096. Log-sum-exp блока, затем объединение результатов строки.
Градиент вычисляется по исходным logits и сохранённому log-sum-exp, без отдельного
сохранения полной матрицы log-softmax. Полные logits остаются для метрик Soup.

## 4. RMSNorm и корректность
Собственные forward и backward. Float32-редукции и порядок приведения типов Qwen.
Веса нормализации заморожены. Тесты значений и градиентов против PyTorch.
SwiGLU starter обозначен как чужой пример.

## 5. Измерения
Таблица base / candidate / ratio: время, MiB, eval loss.
Отдельно доля собственных ядер и число PASS из 10.
До реального запуска писать «не измерено». Источник цифр: сохранённая Kaggle-версия.

## 6. Воспроизводимость и ограничения
GitHub SHA, публичная Kaggle-версия, команды запуска.
Порог 5%, дополнительные launch, память полных logits, специализация dtype/формы.
Следующий шаг определяется фактическими результатами.
