# Текст готового видео

Видео: artifacts/Soup_Kernel_Lab_Demo.mp4, 2:39. Синтетическая озвучка Microsoft Irina.

1. Представляю Суп Кернел Лаб. Это проект по оптимизации вычислений при дообучении языковой модели. В репозитории есть собственные ядра Тритон, тесты, инструкции и воспроизводимый ноутбук. Сейчас подтверждена арифметика решения. Ускорение на видеокарте пока не заявляется.

2. Условия эксперимента фиксированы. Модель Квен полтора миллиарда параметров, квантование и обучение адаптера. Используются двести пятьдесят шесть казахских примеров, шестьдесят четыре шага и одна видеокарта Тэ четыре. Данные, параметры обучения и официальный проверяющий код сохранены.

3. Реализовано пять собственных ядер. Три вычисляют функцию потерь: сначала суммы по блокам словаря, затем итоговый лосс, затем градиент. Это позволяет не сохранять полный логарифм софтмакса. Ещё два ядра выполняют прямой и обратный проход нормализации. Суммы считаются с повышенной точностью.

4. Автоматические проверки уже прошли на Гитхабе. Двадцать тестов проверяют обычные и резервные пути. Ещё десять запускают само тело ядер через интерпретатор Тритон. Это подтверждает вычисления и индексацию, но не заменяет проверку компиляции и скорости на видеокарте.

5. Здесь показаны реальные результаты локального демо. Для трёх размеров словаря сравниваются функция потерь и градиенты с Пайторч. Все сравнения прошли. Даже для словаря сто пятьдесят одна тысяча девятьсот тридцать шесть ошибка функции потерь равна нулю. Отчёт создаётся командой, показанной на экране.

6. Это страница с сохранённым результатом запуска. В ней видны исходные значения, ошибки, статус каждого сравнения и условия эксперимента. Рядом сохраняются машиночитаемый результат и контрольные суммы. Демо можно повторить на обычном компьютере без ключей и видеокарты.

7. Код и материалы доступны в открытом репозитории. Подготовлен ноутбук Кагл для полного запуска на Тэ четыре. Следующий этап — измерить время, проверить качество и все десять правил. До успешного прогона эти показатели остаются неподтверждёнными. Спасибо за внимание.
